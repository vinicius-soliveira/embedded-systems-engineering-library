# Embedded Systems Engineering Library

A structured personal technical library covering embedded systems, firmware, RTOS, Embedded Linux, C/C++, Rust, FPGA, digital verification, DSP, industrial communications, advanced SoC architecture, security, toolchains and systems engineering.

The collection is organized into thematic parts and volumes, progressing from fundamentals to production-level architecture, implementation, verification, debugging and system integration.

## Scope

The library is intended to serve as:

- a long-term technical reference;
- study material for embedded and digital systems engineering;
- preparation for technical interviews;
- a bridge between theory, implementation and debugging;
- a practical reference for firmware, FPGA, SoC and systems work.

The emphasis is on **engineering depth rather than topic count**. Complex subjects are treated with context, implementation details, trade-offs, failure modes, debugging strategies, examples, laboratories and design-oriented reasoning.

## Design Philosophy

The material follows a recurring engineering progression:

```text
concept
   ↓
mental model
   ↓
implementation
   ↓
hardware/software behavior
   ↓
trade-offs
   ↓
verification
   ↓
debugging
   ↓
production considerations
```

Whenever useful, the volumes include:

- concise interview-oriented answers;
- deep technical explanations;
- architecture and timing diagrams;
- C, C++, Rust, SystemVerilog, VHDL and pseudocode examples;
- hardware/software interaction analysis;
- design trade-offs and common failure modes;
- laboratories and case studies;
- engineering checklists;
- review questions and self-assessment.
